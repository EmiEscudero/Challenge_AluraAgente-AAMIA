# Envío Challenge Alura Agente

¡Felicitaciones por completar tu Agente Inteligente!
Has llegado al final de este desafío y estamos seguros de que construíste un grandioso proyecto. Antes de enviar tu agente inteligente, revisa atentamente las siguientes indicaciones para asegurar que la entrega se realice correctamente.

⚠️ Antes de enviar tu Challenge
Verifica que la URL de tu proyecto sea correcta y que el repositorio esté accesible públicamente.
El sistema solo acepta URLs de repositorios de GitHub.
Asegúrate de que tu repositorio incluya todos los elementos solicitados en el desafío, como el código fuente, el README y las evidencias del despliegue.
Pasos para realizar la entrega
Ingresa la URL de tu repositorio de GitHub.
Haz clic en Enviar enlace.
Selecciona si autorizas o no el uso de tu proyecto con fines pedagógicos y educativos.
Una vez colocada la URL del desafío debes descargar el badge y solo después enviar tu proyecto.
Una vez completados los pasos anteriores, haz clic en Enviar proyecto para finalizar tu entrega.
Intentos de entrega
Dispones de 5 intentos para realizar la entrega de tu Challenge. Te recomendamos revisar cuidadosamente toda la información antes de enviar tu proyecto.
